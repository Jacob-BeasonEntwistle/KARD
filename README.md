# KARD
## Kindly Automated Retrieval Droid

This is a game about a robot who collects debris in outer space. He was thrown from his ship and stranded in space, his one mission is to retrieve as much lost cargo as he can. 

Originally my 2D game programming project for year 1 semester 1 of university, KARD has now become a complete game full of features that I take pride in.

## Features
- 2D side scroller
- Multiplayer
- Enemies
- Custom Textures/Sprites
- Custom SFX
